## 3. Self-contained single-file publish: what must accompany the exe

`dotnet publish -r win-x64 --self-contained` (see `publish.ps1`) embeds the .NET runtime and WinForms in the exe.
The MIT license requires its copyright and permission notice to be included with all copies or substantial
portions, and the runtime ships a large aggregate of third-party notices. Therefore:

1. Place `LICENSE`, `NOTICE` and `THIRD-PARTY-NOTICES.md` beside the exe (or at the root of the zip/installer).
2. Copy the runtime's own `THIRD-PARTY-NOTICES.TXT` (in the `microsoft.netcore.app.runtime.win-x64` NuGet
   package, about 93 KB; covers zlib-ng, Brotli, zstd, Unicode data, LLVM, mimalloc, and others) next to the exe,
   for example as `THIRD-PARTY-NOTICES-dotnet.txt`. Suggested addition to `publish.ps1` (not applied by the
   licensing agent, which does not own that file).
3. Optionally show the notices from an "About" dialog.

## 7. Compatibility with AGPL-3.0-only (informational)

* MIT and BSD-3-Clause components (HtmlAgilityPack, .NET runtime, WinForms, WebView2 SDK) are compatible with
  GPLv3/AGPLv3: the combined work is conveyed under AGPL-3.0-only while each component keeps its own notice.
* Apache-2.0 (xunit) is compatible with GPLv3/AGPLv3 and is test-only anyway.
* **WebView2 SDK native loader (`WebView2Loader.dll`)** ships as a binary in the Microsoft package under the BSD-3-Clause
  file above. BSD-3-Clause permits binary redistribution, but whether its source must be part of AGPL "Corresponding Source"
  depends on the "System Libraries" and "specifically designed to require" wording of AGPL section 1: unsettled. Practical mitigation: state in the source offer that the loader and the .NET runtime are unmodified Microsoft
  components, link their upstream sources (https://github.com/dotnet/runtime, https://aka.ms/webview), and do not modify them.
* **WebView2 Evergreen Runtime** is a Microsoft system component installed on the user's machine (Windows 11 / Microsoft
  Edge) and is not conveyed by this project, so it is outside the Corresponding Source. If a future installer ships Microsoft's
  Evergreen bootstrapper, get the redistribution terms checked against AGPL.
* Each binary release must also carry the corresponding-source offer.
